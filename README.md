# Чат Хорошее настроение (Spring Boot + H2 + Thymeleaf + Maven)

Учебный проект практики: веб-чат хорошего настроения с расширенной анкетой регистрации (35+ вопросов),
ролевой системой и модерацией (бан, мут, удаление сообщений), **Upgrader** наград, ботами,
ответами на сообщения, компасом, «счётчиком Гейгера», ретро-радио, калькулятором и Яндекс.Картами.

## 📦 Как распаковать и запустить

1. Распакуйте архив `chat-good-mood-ru-gruzin.zip` в любую папку (например, `webapp`).
2. Убедитесь, что установлены **Java JDK 17+** и **Apache Maven (`mvn`)**.
3. Откройте терминал в папке `webapp` и запустите:
   - **Linux / macOS**: `./start.sh` (или `mvn clean spring-boot:run`, либо `./mvnw spring-boot:run`)
   - **Windows**: двойной клик по `start.bat` (или `mvn clean spring-boot:run`)
   > ⚠️ Важно: используйте именно **`spring-boot:run`** (а не `spring-boot:start`, который требует JMX MBean на порту 9001).
4. После запуска откройте в браузере:
   - 👉 Сайт: **http://localhost:8099/**
   - 👉 База данных H2: **http://localhost:8099/h2-console** (`jdbc:h2:file:./data/chatdb_v2;AUTO_SERVER=TRUE`, User: `sa`, Password пустой)
